# 공개 코드 전달 범위

정식 이름은 동상이몽입니다. 로컬 구현 이력은 정본에 보관하고, 기존 GitHub 팀 소개 이력 위에 검토한 소스 스냅샷을 추가했습니다. 음성·영상·PDF·원본 기획 자료·개인 회의 원문·DB·인증정보는 공개 이력에 넣지 않습니다. 프로그램 코드·테스트·합성 JSON 픽스처·UI 이미지·선별된 개발 검증 문서·실시간 공유 서비스 소스를 포함합니다.

기존 기술 문서에서 이 묶음에 없는 자료를 참조할 수 있습니다. 제외한 기존 음성 평가 파일은 필요하면 별도로 재생성해야 하며, 공개 묶음에 실제 녹음을 예시로 대신 넣지 않았습니다.

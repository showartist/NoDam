## 아직 "된다" 고 말하면 안 되는 기능

- **한국어 실제 3인 회의의 화자분리 정확도** — 배선은 됐지만 품질을 재지 못했습니다. TTS 한 목소리를 피치만 바꾼 데이터로는 화자분리를 평가할 수 없습니다.
- 마이크 입력부터 시작하는 실시간 파이프라인 (현재는 파일 업로드만)
- 화자 이름 자동 인식 (`SPEAKER_01` 까지만 자동, 이름은 사람이 지정)
- 동상이몽 지수의 정확도와 임계치 — 현재 점수는 미해결 이슈 수이며 사람 간 해석 거리 지표가 아닙니다
- 다중 레퍼런스 비중을 반영한 이미지의 실시간 생성
- 여러 회의에 걸친 RAG, 버전 이력, 일관성 검사
- 장시간(30분 이상) 회의 — 업로드 25MB·타임아웃 60초 제약

상세 제약은 [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md)를 확인해주세요. 과거 VERIFIED_STATUS.md는 이 공개 묶음에 포함하지 않았습니다. 최신 검증 근거는 [팀 공유용 개발 현황](TEAM_PROGRESS_20260915.md)에서 연결한 문서를 확인해주세요.

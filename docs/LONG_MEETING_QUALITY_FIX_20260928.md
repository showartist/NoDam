# 긴 회의 화자·후속 합의 검사 수정 — 2026-09-28

## 근본 원인과 변경

1. 화자 서비스가 없을 때 조각별 화자 ID가 전체 회의의 서로 다른 사람으로 저장·분석됐다. 전체 음성 화자 분석 서비스를 실제 가동했다. 앞으로 실패 시 조각 ID를 미확인으로 내보내며, 기존 미확인 전사도 읽기 단계에서 사람 간 비교에 사용하지 않는다. 사람이 명시적으로 수정한 이름은 유지한다.
2. 문맥 검사는 인용 주변 발언만 봤다. 이제 검토 범위의 전체 시간순 발언을 함께 보고, 뒤의 수용·번복 및 남은 조건을 검사한다. 정리된 안건은 유효한 근거 ID가 있을 때 확인 목록에서 제외하고 사유를 분석 통계에 남긴다. 이를 참가자 승인으로 자동 기록하지 않는다. 판정 실패 시 안건을 유지하며 실패를 표시한다.
3. '일단' 한 단어로 조건을 생성하던 규칙을 제거했다. 실제 확인·테스트·보류 등의 명시적 조건 검사는 유지한다.
4. 화자 미확인 발언도 인용 근거가 있으면 실행 정보 확인 질문은 남길 수 있다. 미확인 발언들을 서로 다른 사람의 충돌이라고 세지는 않는다.

## 실제 녹음으로 확인한 범위

사용자가 지정·승인한 31분 41.88초 녹음의 기존 64개 성공 체크포인트를 재사용했다. 음성 원본과 이전 분석은 변경하지 않고 별도 비교 회의를 만들었다. 추가 STT 요청은 하지 않았다.

전체 음성 화자 분석은 로컬 모델로 성공했다. 첫 실행 42.908초, 전사 결합 경로 재검증 28.184초. 144개 조각별 라벨 대신 6개 자동 음성 그룹, 발언 434개로 재구성됐다. 원래 단어 1,668개는 유지됐다. 화자에 따라 발언 경계가 다시 나뉘어 발언 수가 달라진다. 자동 그룹 6개는 실제 참석자 6명이나 이름을 검증했다는 뜻이 아니다.

수정 후 실제 OpenRouter 재분석은 자동 승인 검토가 재전송에 대한 명시적 승인을 요구하며 차단했다. 사용자에게 같은 회의 전사문·화자 라벨의 재전송과 추가 API 비용을 안내하고 승인을 요청했다. 승인이 오기 전에는 새 프롬프트가 실제 회의에서 과잉 탐지를 줄였다고 주장하지 않는다. 후속 합의 검사의 현재 검증 범위는 합성 회귀 검사다.

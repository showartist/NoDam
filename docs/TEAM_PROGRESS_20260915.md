# 동상이몽 — 팀 공유용 개발 현황

기준일: 2026-09-15 · 저장소: [showartist/NoDam](https://github.com/showartist/NoDam)

## 무엇을 만드는가

동상이몽은 회의에서 같은 말을 서로 다른 뜻으로 이해하는 부분을 찾아, 함께 확인하고 결정하도록 돕는 프로그램입니다. 예를 들어 모두 “따뜻한 광고”를 원해도 한 사람은 가족이 있는 식탁을, 다른 사람은 사람이 떠난 빈 부엌을 생각할 수 있습니다. 누가 맞는지 점수로 평가하지 않고, 각자의 뜻과 필요한 조건을 비교합니다.

## 현재 사용할 수 있는 기능

| 기능 | 할 수 있는 일 |
| --- | --- |
| 회의 입력 | 녹음 파일이나 회의록을 넣어 전사·분석합니다. |
| 회의 중 전사 | 마이크 입력을 약 20초 단위로 전송합니다. 글이 표시되기까지 API 처리 시간이 추가됩니다. |
| 회의 중 분석 | 정해 둔 회의 목적을 기준으로 3·5·10분 간격으로 최근 대화를 확인합니다. |
| 생각 비교 | 화자별 해석, 근거 발언, 확인할 질문을 보여줍니다. |
| 함께 결정 | 각자의 뜻·예시·조건을 확인하고, 동의·우려·추가 논의·판단 보류를 기록합니다. |
| 후속 작업 | 담당자·기한·완료 기준과 변경 이력을 남깁니다. |
| 제작 자료 | 이미지 생성 API와 제작 자료 비교 기능을 연결했습니다. |

의미 확인과 동의는 현재 진행자가 참가자에게 확인한 내용을 기록하는 방식입니다. 참가자 본인이 로그인해 투표한 기록은 아닙니다. AI는 후보를 제안하고, 사람이 확인해야 해결·합의로 남깁니다. 근거 없는 0–100 동상이몽 점수는 제거했습니다.

## 어디까지 검증했는가

- 9월 13일 전체 검사 기록: **320 tests / 307 pass / 13 skip / 0 fail**, 타입 검사와 빌드 성공. 이번 문서 갱신에서 이 수치를 새로 측정했다고 주장하지 않습니다.
- 마이크 흐름은 실제 API와 가상 마이크로 시험했습니다. 실제 여러 사람이 장시간 회의한 정확도 검증과 구별해야 합니다.
- 사용자가 제공한 가상 광고 회의 대사 94개를 실제 OpenRouter API로 분석했습니다. 약 2분 34초 후 확인할 안건 4건, 합의 후보 0건을 반환했습니다.
- 이 가상 회의에서 인물 등장 여부, 따뜻함의 의미, A/B안 제작 조건, 감독 참여 여부를 짚었습니다. 이는 단일 사례이며 전체 정확도 지표가 아닙니다.
- 9월 15일 로컬 서버를 재가동하고 해당 분석 화면과 실시간 회의 화면이 HTTP 200으로 열리는 것을 브라우저에서 확인했습니다.

가상 회의는 텍스트 분석 시험입니다. 대본의 4시간 40분은 실제 녹음 시험 시간이 아닙니다. 원문 대본과 개인 DB, 분석 응답 원본은 이번 공개 업데이트에 포함하지 않습니다.

## 아직 보완할 부분

1. **분석의 정확성:** 가상 회의에서 모호한 승인 발언을 별도 질문으로 짚지 못했고, 원문에 없는 촬영 조건을 요약에 덧붙였습니다. 자동 문맥 검사도 이 오류를 잡지 못했습니다.
2. **뜻을 풀어주는 질문:** 단순히 결정권자를 묻는 데서 더 나아가, 각자의 필수 조건과 조정 가능한 조건을 확인하도록 개선해야 합니다.
3. **실제 회의 안정성:** 여러 사람이 말할 때의 화자 구분 정확도와 장시간 사람 음성 운영 검증이 남아 있습니다.
4. **외부 실시간 공유:** 공유 서버 소스는 포함되어 있지만 인증 설정과 실제 외부 전송 검증이 남아 있습니다.
5. **참가자 직접 확인:** 본인 인증, 각자의 응답, 외부 공동 편집은 아직 완료되지 않았습니다.

현재는 **로컬 컴퓨터에서 시연할 수 있는 MVP**입니다. 오프라인 LLM이나 Astra 전사 엔진을 구현한 것은 아닙니다. 공유 웹페이지가 열리는 것과 전체 앱이 외부에서 실시간으로 동작하는 것은 별개입니다.

## 팀원이 실행하는 방법

Node.js 22 이상이 필요하고, 오디오 분할·변환에는 ffmpeg가 필요합니다.

```bash
git clone https://github.com/showartist/NoDam.git
cd NoDam
npm ci
cp .env.example .env.local
# .env.local의 OPENROUTER_API_KEY에 본인의 키 입력
npm run dev
```

브라우저에서 http://localhost:3210 을 엽니다. 새 회의에 목적과 회의록을 입력해 분석하거나, 빈 회의에서 실시간 녹음을 시작합니다. 마이크 권한은 브라우저에서 허용해야 합니다. 실제 API 이용에는 본인의 키와 이용 비용이 필요합니다.

개발자의 localhost 주소와 개인 회의 DB는 팀원 컴퓨터로 자동 공유되지 않습니다. GitHub는 소스 공유 저장소이며 앱 실행 서버가 아닙니다.

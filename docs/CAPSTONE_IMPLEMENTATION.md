## 동상이몽 지수 기준과 효율

정본 함수: `lib/analysis/dongsangIndex.ts`의 `calculateDongsangIndex` (`dongsangAnalyzer.ts`에서도 export).
실제 화면은 v2 분석 API를 사용한다. 옛 자유문장 분석기에서 근거 없이 점수를 생성하지 않는다.

**점수 = 100 × 의미가 다르다고 판정된 항목·화자 쌍 수 / 의미 판정이 완료된 항목·화자 쌍 수.**

- 동일 가중치, 소수점 한 자리, 범위 0~100. 심각도와 LLM confidence로 점수를 부풀리지 않는다.
- 실제 화자·원문 인용·문맥 검사를 모두 통과한 입장만 집계한다.
- 기존 판정 모델의 `same / different / unclear` 결과를 저장해 재사용한다. 지수 계산에는 추가 API 호출과 비용이 없다. 기존 문맥 판정의 해시 캐시도 계속 사용한다.
- 다른 문자열 자체를 의미 충돌로 확정하지 않는다. `unclear`·문맥 미확인·판정이 없는 옛 기록은 미판정으로 표시한다. 정규화 문자열이 같은 경우는 동일 판정 가능하다.
- 같은 근거·항목·화자 쌍은 한 번만 센다. 서로 다른 중복 판정은 보수적으로 미판정 처리한다.
- 해소·제외 안건과 과거 결정 비교는 현재 사람 사이의 지수에서 제외한다.
- 비교 대상이 없으면 `null`(계산 보류). 0점이나 합의로 둔갑시키지 않는다.
- 판정 커버리지 = 판정 완료 / 전체 비교 후보 × 100. 점수 옆에 미판정 수와 함께 표시한다.
- 잠정 경보 기준: 30 미만 low, 30 이상 review, 60 이상 alert. 단위 테스트로 경계를 검증한다.

**해석 범위:** 분석기가 찾아낸 활성 안건의 해석 차이다. 회의 전체의 갈등 확률이나 과학적으로 검증된 심리 척도가 아니다. 명시적 합의 항목 전체를 분모로 조사하는 방식도 아니다. 따라서 분석기가 놓친 안건은 반영되지 않으며, 적은 표본과 낮은 커버리지는 함께 보아야 한다. 팀 실제 회의에 대한 정답 라벨로 임계치와 탐지 품질을 보정해야 한다.

## 남은 검증 범위

- 실제 사람 3인 녹음의 화자 분리·자기소개 추출 정확도는 미측정. 합성 한 목소리로 화자분리 정확도를 주장하지 않는다.
- 사이드카가 없는 분할 전사는 `chunked+none`, 화자 상태 `unsupported`. 조각별 번호를 같은 사람이라고 간주하지 않는다.
- 30분 실제 회의 전체를 외부 STT로 전사한 결과는 아님. 분할과 병합은 30분 파일, 외부 API는 200초 합성음으로 각각 검증했다.
- 로컬 서버 대상. 배포 플랫폼의 요청 본문 상한·전체 실행 시간 제한은 별도이며 장시간 작업 큐는 이번 범위에 없다.
- 보조 낱말 규칙은 부정·다른 장면·자기 정정의 모든 한국어 문맥을 이해하지 못한다. 핵심 지수는 v2 근거·문맥 검사 결과를 사용한다.
- 과거 저장된 분석에 화자 쌍 판정이 없으면 지수가 보류될 수 있다. 다시 분석하면 새 판정이 저장된다.

원래 저장소의 회의 음성을 외부로 보내는 시도는 자동 승인 검토에서 차단됐다(민감한 음성의 외부 전송 승인 불명확). 해당 녹음은 보내지 않았으며, 이후 검증에는 AI가 작성한 가상 대사와 TTS 합성음만 사용했다.

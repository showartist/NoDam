# MVP v2 1단계 구현·검증

2026-09-28 · 계획: [MVP v2 실행 계획](MVP_V2_PLAN_20260928.md)

## 바꾼 것과 이유

기존 /new는 전사가 필수이며 저장 직후 장면 추출을 실행했다. 일반 회의를 간단히 준비하거나 AI 연결 없이 원문만 저장하기 어려웠다. 기존 제작 화면을 유지하며 /v2 → /v2/new → /v2/m/[id]로 별도 진입 경로를 추가했다.

- 회의명·목적만으로 빈 회의 저장. 새 프로젝트 또는 기존 프로젝트 선택. 실시간·오디오 입력은 기존 화면에 연결.
- 텍스트 직접 입력과 UTF-8 TXT·MD 가져오기, 자료 유형(실제/가상/예정), 발언 미리보기와 명시적 확인.
- 원문은 meetings.raw_transcript, 분석용 발언은 utterances에 저장. 화자 없는 줄을 버리거나 직전 화자로 자동 연결하지 않는다. 한 줄을 한 기록으로 보존하고 지원하지 않는 시간 형식도 원문으로 남긴다.
- 저장은 AI 호출과 분리. 트랜잭션으로 실패 시 부분 생성 방지. 같은 요청의 재시도는 동일 회의 반환, 내용이 바뀐 동일 요청은 409.
- 회의 목적·종류·자료 유형을 분석 맥락에 전달. v2 새 회의에는 과거 결정 맥락을 자동 주입하지 않는다. 기존 회의의 동작은 유지.
- 가상·예정 자료는 합의 후보를 실제 합의로 저장하지 않고 안건을 open으로 유지한다. 공동 확인·참가자 확인/응답·v2 결정 원장 승인을 서버에서 차단한다. 이전 장면 추출 API는 이 자료 유형에 409를 반환한다.
- 실패한 분석 기록은 v2 화면에서 실패로 표시. 기존 current-run 조회는 실패를 제외하므로 최근 run 이력으로 표시하는 방식으로 연결했다.
- 실제 저장 DB 경로 안내. 프로젝트 폴더 지정은 아직 미구현.

전체 테스트 합계는 npm test가 실행한 14개 TAP 요약의 합이다. 이전 320 / 307 pass / 13 skip에 신규 통합 테스트 11개가 추가됐다. 기존 테스트를 삭제하거나 기대값을 완화하지 않았다.

브라우저 검증: 미리보기 확인 전 저장 불가 → 가상 자료 저장 → 새로고침 → 원문 동일성 → 합성 모델 실패 안내 → 원문 보존 → 같은 프로젝트의 빈 회의 생성 → 실시간 목적 사전 입력. 390px 모바일에서 가로 넘침 없음. 화면 이미지도 확인했다.

검증 데이터는 합성이며 외부 모델 응답·장애는 주입한 테스트 응답이다. 이번 작업에서는 실제 마이크 녹음, 실제 외부 AI 분석 품질, 화자 정확도, 외부 팀 공유를 새로 검증하지 않았다.

로그·브라우저 검증 스크립트·스크린샷은 로컬 .data/verification/mvp-v2-20260928/에 보존했다. 데모 DB는 기존 회의 DB와 분리했다. 로컬 데모: http://localhost:3212/v2 (서버가 실행 중일 때).

## 다음 단계와 남은 경계

- TXT·MD만 새 파일 입력 경로로 제공한다. SRT·VTT 시간 보존, 복잡한 대본 구조화, 원본 파일 자체의 보관·수정본 버전 관리는 다음 단계.
- 오디오 입력·실시간 본회의·상세 분석은 기존 화면을 재사용한다. 새 3분 요약/15분 리포트 화면과 종료·재개는 아직 구현하지 않았다.
- 가상·예정 자료의 음성 입력은 이번 단계에서 지원하지 않는다. 텍스트로 입력한다.
- 참가자 본인 인증·회의별 참석자 관리·화자/전사 편집·자동 재분석·프로젝트 폴더 저장은 계획 단계.
- 기존 회의는 자료 유형 미지정으로 표시하며 과거 기록을 추정해서 바꾸지 않는다.
- 신규 v2 문서·코드는 로컬 개발 브랜치에만 반영했다. 기존 외부 공유 사이트·GitHub main 배포는 이번 작업에서 하지 않았다.

# 동상이몽 — 4조 노담팀

카이스트 CTxAI 마이크로 디그리 과정 - 노담팀

**같은 말 아래 서로 다른 해석을 확인하고, 함께 실행할 결정으로 연결하는 회의 프로그램입니다.**

주제 이탈뿐 아니라 의미 차이와 앞뒤 발언의 불일치 후보를 원문과 함께 보여줍니다. 참가자가 각자의 뜻·예시·실행 조건을 확인하고, 같은 뜻인지·보완 관계인지·선택이 필요한 차이인지 정리합니다. AI 후보를 자동으로 합의나 사람의 능력 평가로 바꾸지 않습니다.

## 팀 운영 기능 — 2026-09-28

v2에 진행자 접근 보호, 개인 초대 링크로 참가자 직접 응답, 같은 회의 이어 녹음, 종료 당시 기록 보존, DB 백업·복원 도구를 추가했습니다. [팀 운영·설치 가이드](docs/TEAM_OPERATIONS.md)를 참조하세요. 로컬 HTTPS에서 독립 참가자 브라우저 검증과 합성 음성의 실제 API 이어 녹음 검증을 수행했습니다. 외부 운영 서버에는 아직 배포하지 않았습니다.

## 기존 결과물 — 2026-09-13

- 마이크 녹음 → 약 20초 조각 전사 → 고정 목적에 따른 3·5·10분 분석. 표시까지 API 처리 시간이 추가됩니다.
- 원문 근거·중립적인 확인 질문·알림 보류 이유, IndexedDB 녹음 복구와 긴 오디오 분할 처리.
- 해석 비교 카드: 원문 표현 → 참가자별 뜻·예시·조건 → 관계와 공통 조건 정리 → 결정안.
- 진행 동의 / 우려를 남기고 진행 동의 / 추가 논의 / 판단 보류. 미확인은 합의가 아닙니다.
- 해석이나 결정안 변경 시 재확인, 담당자·기한·완료 기준, 변경 이력·JSON 내보내기.
- 이미지 생성 API와 기존 제작 자료 비교 기능.

근거 없는 0–100 동상이몽 점수는 제거했습니다. 확인은 **진행자의 대리 기록과 개인 초대 링크 응답을 구분**합니다. 개인 링크도 실명 인증된 투표는 아닙니다.

## 실행

Node.js 22 이상이 필요합니다. SQLite는 Node 내장 모듈을 사용합니다. 오디오 분할·변환에는 ffmpeg가 필요합니다.

```bash
git clone https://github.com/showartist/NoDam.git
cd NoDam
# PR 병합 전 최신 v2를 받으려면 아래 브랜치를 선택합니다.
git switch feat/mvp-v2-team-operations-20260928
npm ci
cp .env.example .env.local
# .env.local의 OPENROUTER_API_KEY를 본인의 키로 설정
npm run dev
```

브라우저에서 **http://localhost:3210/v2** 를 엽니다. 실제 API 키, 로컬 DB, 실제 회의 녹음·전사 파일은 이 저장소에 포함하지 않습니다. 녹음 파일과 원본 기획 자료는 공개 업로드 묶음에서 제외했습니다.

1. 새 회의를 만들고 오늘 결정할 목적을 입력합니다.
2. 실시간 회의를 시작하거나 회의 전사·음성을 넣습니다.
3. AI 후보의 **함께 확인하기** 또는 상단 **함께 결정**으로 이동합니다.
4. 원문에서 안건을 등록하고 **해석 비교 카드**를 시작합니다.
5. 참가자에게 각자의 뜻·예시·조건을 확인하여 기록합니다.
6. 비교를 정리하고 조건을 결정안에 가져온 뒤 진행 동의를 받습니다.

## 검증과 한계

마지막 전체 검사: **320 tests / 307 pass / 13 skip / 0 fail**, 타입 검사·빌드 성공. 해석 비교 카드는 합성 3인 회의로 브라우저 입력·확정·새로고침·내보내기를 확인했습니다. 이후 이름 변경은 타입 검사와 홈·새 회의·해석 비교 화면에서 확인했습니다. 합성 검증을 실제 다인 회의 정확도로 주장하지 않습니다.

```bash
npx tsc --noEmit
npm test
npm run build
```

외부 팀원에게 실시간으로 보내는 연결은 공유용 인증 설정과 실제 전송 검증이 남아 있습니다. 실제 다인 회의 화자 정확도, 장시간 사람 음성 운영, 본인 인증과 외부 공동 편집은 완료로 표시하지 않습니다. 지금은 로컬 앱과 외부 API를 연결하는 방식이며 오프라인 LLM이나 Astra 전사 엔진이 아닙니다.
